# Геоаналитическая панель транспортных потоков Астаны

Улучшенная архитектура Flask приложения для анализа GPS данных с использованием ИИ.

## Структура проекта

```
├── src/                      # Исходный код
│   ├── config/              # Конфигурация
│   │   ├── __init__.py
│   │   └── config.py        # Настройки приложения
│   ├── models/              # Модели данных
│   │   ├── __init__.py
│   │   └── data_models.py   # Классы данных и dataclasses
│   ├── services/            # Бизнес-логика
│   │   ├── __init__.py
│   │   ├── ai_service.py    # Работа с Google AI
│   │   ├── data_service.py  # Загрузка и обработка данных
│   │   └── analysis_service.py  # Аналитические операции
│   ├── api/                 # REST API endpoints
│   │   ├── __init__.py
│   │   ├── stats_routes.py  # Статистика и базовая аналитика
│   │   ├── analysis_routes.py  # Трафик и аномалии
│   │   └── utils_routes.py  # Экология и утилиты
│   └── utils/               # Вспомогательные утилиты
│       ├── __init__.py
│       ├── geocoding.py     # Геокодирование адресов
│       └── visualization.py # Создание графиков и карт
├── templates/               # HTML шаблоны
│   └── index.html
├── app.py                   # Старое приложение (сохранено)
├── app_new.py              # Новое модульное приложение
├── requirements.txt         # Python зависимости
└── README.md               # Документация
```

## Установка и запуск

### Быстрый запуск с новой архитектурой
```bash
python app_new.py
```

### Запуск со старой архитектурой
```bash
python app.py
```

### Установка зависимостей
```bash
pip install -r requirements.txt
```

## Основные компоненты

### Сервисы
- **AIService**: Работа с Google Gemini AI
- **DataService**: Загрузка, очистка и кэширование GPS данных
- **AnalysisService**: Кластеризация, поиск аномалий, анализ безопасности

### API Endpoints
- **Stats**: `/api/stats`, `/api/speed-distribution`, `/api/zones`
- **Analysis**: `/api/traffic-heatmap`, `/api/anomalies`, `/api/safety-analysis`
- **Utils**: `/api/eco-analysis`, `/api/get-address`

### Модели данных
- Типизированные dataclasses для всех сущностей
- Процессоры для конвертации между форматами

## Конфигурация

Переменные окружения:

GOOGLE_API_KEY=your_key
